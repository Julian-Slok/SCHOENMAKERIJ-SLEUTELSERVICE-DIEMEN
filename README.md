# SCHOENMAKERIJ-SLEUTELSERVICE-DIEMEN
Moderne, responsive website voor Dr.Shoe / Schoenmakerij &amp; Sleutelservice Diemen. Met informatie over schoenreparatie en sleutelservice, openingstijden, route en telefonisch contact voor afspraken. Gebouwd met HTML, CSS en JavaScript, inclusief mobiele navigatie en scrollanimaties.
