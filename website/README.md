# Schoenmakerij & Sleutelservice Diemen

Een zelfstandige website met HTML, CSS en JavaScript.

## Bekijken

Open `index.html` in je browser. Je kunt de map `website` ook openen in Visual Studio Code en daarna `index.html` met een browser-preview bekijken.

## Bestanden

- `index.html` — pagina-inhoud en navigatie
- `styles.css` — vormgeving, responsive layout en animaties
- `script.js` — mobiel menu en scroll-onthullingen

De openingstijden zijn overgenomen van een online bedrijvengids en kunnen afwijken. Bel bij twijfel vooraf.
